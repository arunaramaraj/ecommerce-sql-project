# E-Commerce SQL Project

## Description
This project is developed using Oracle SQL. It simulates an e-commerce system where users can place orders and make payments.

## Tables Used
- Users
- Products
- Orders
- Order_Items
- Payments

## Features
- Created relational database tables
- Used Primary Key and Foreign Key
- Performed SQL queries (SELECT, JOIN, GROUP BY)
- Inserted sample data
- Managed orders and payments

## Tools Used
- Oracle SQL
